# Literature review (protocol v0.1, written before any outcome data were acquired)

**Verification level.** Every entry below was checked for bibliographic details (authors, year,
title, venue, DOI/URL) against at least one index (publisher DOI landing page, RePEc/IDEAS,
arXiv, Project Euclid, or EconBiz) on 2026-11-21. **No full text was read at this stage.**
"Finding" columns summarise the published abstract / index record only and are marked
`abstract-only`. Entries must be upgraded to `full-text` (with page references) before the
manuscript cites a specific result beyond the abstract. Trading blogs and AI-generated summaries
were not used as evidence.
